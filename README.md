# WATER · 粒子水体实验室

这次实现使用真实的三维粒子状态计算水流，不再通过固定矩形的波浪高度场制造运动。

## 交互

- **搅水**：按住拖动，对附近粒子施加推动和旋转力；轻点产生飞溅。
- **注水**：按住向对应位置持续注水，WebGPU 默认 50000 个物理粒子，上限 50000；WebGL2 回退默认 15000，上限 30000。水量 +/- 每次注入或移除 500 个粒子。
- **模拟精度**：15000 / 30000 / 50000（WebGPU）；切换重置水体，以近似相同水量提高分辨率，精细模式计算成本更高。
- **观察**：拖动旋转、滚轮缩放；任何模式下右键或 Shift + 拖动均可旋转。
- **晃动容器**：施加短暂的横向惯性力，引起撞壁、回流与飞溅。
- **参数**：搅动力度、黏性、重力、时间速度、光照、反射、水底光纹。
- **显示计算粒子**：切换为独立粒子视图，直接观察水体的离散计算单元。
- **键盘**：聚焦画布后，方向键旋转，+/- 缩放，回车或空格产生飞溅。

## WebGPU 与 5 万粒子

支持 WebGPU 时自动使用 `app/webgpu/`，不支持或初始化失败时回退 WebGL2。右上角显示实际后端；`?backend=webgl` 可强制使用原后端对比。5 万粒子按钮只在 WebGPU 下启用，不进行 CPU 物理回退。

- 粒子、刚体和中间结果全部保存在 GPU storage buffers。计数、分块前缀和、scatter 共五个 compute dispatch 建立完整单元范围，没有固定桶容量或丢弃邻居。
- 保留三轮 PBF 密度校正和两轮 DFSPH 速度散度投影；第二轮密度校正后重建一次网格，并同步重排反作用力，覆盖鸭子接触造成的额外位移。它仍是混合求解器，不是完整 DFSPH。
- 重建前更新最终位置网格；每个体素用计算着色器累加完整邻域的各向异性核。保持 128×160×96 分辨率、核形状、等值面阈值与三轴表面滤波，使用 float32 密度；不采用定点密度原子加法。相邻 X 单元合并读取，密度工作组为 8×4×1，减少切片间不一致的访问。
- 物理、密度、绘制使用独立命令缓冲，一次有序提交；最多两帧在途。暂停时复用密度，调试粒子模式跳过重建，隐藏页面暂停提交。反射关闭时直接跳过反射求交。
- 水体厚度吸收、Fresnel、折射和原始鸭子模型继续保留；无 `float32-filterable` 的设备使用手动三线性采样。

macOS / Metal 原生验证：`npm run test:webgpu`；完整帧测量：`npm run benchmark:webgpu -- 50000`。原生测试需要图形设备权限。详细结果与局限见 [WebGPU 迁移记录](docs/webgpu-migration.md)，这些数字不能当成浏览器 FPS。

### 表面张力、统一水面与较小水滴（实验）

主粒子数量、质量、物理作用半径和原有压力/浮力系统保持原来。移除了薄片专用物理、扁平椭球片面和次级小水滴；通用表面张力通过原有邻域计算凝聚力与短程排斥，复用速度平滑遍历，不增加默认求解 pass。

所有主粒子都进入同一个连续密度场。相邻水滴通过密度叠加形成连通水面，一般各向异性重建顺着粒子分布成形。孤立主粒子的解析显示轮廓半径缩至原来的 72%（轮廓体积约 37%），随邻居增多平滑淡出；没有改变每颗粒子的物理体积或总水量。该轮廓只是避免小水滴被体素采样漏掉，不会生成额外粒子。

物理面板有“表面张力”，光影面板有“精细水滴”。实现、限制和验证见 [统一水面记录](docs/unified-primary-water.md)。`npm run test:webgpu:surface` 检查聚合和短程稳定性；`npm run test:webgpu:details` 检查显示半径、连续密度融合及无额外粒子。本版通过 GitHub Actions 自动部署到 GitHub Pages。

## WebGL2 回退：GPU 模拟与连续水体重建

回退路径为 `app/gpu-fluid.ts` 和 `app/gpu-fluid-shaders.ts`，使用 WebGL 2 浮点帧缓冲执行 GPGPU；不再启动 CPU 物理 Worker。JS 只处理输入、粒子数量与固定步进调度、提交绘制指令，不遍历粒子求解，也不逐帧上传或读回粒子/密度数组。`fluid-simulation.ts`、`fluid-volume.ts` 和旧 Worker 保留为 CPU 参考实现与回归测试，不参与网页数值计算。

- 256 × 128 RGBA32F 纹理保存粒子的位置、速度和压力；默认 15000，最多 30000 个有效粒子。
- 每个 1/60 秒子步用 GPU 稳定基数排序建立空间网格，再并行二分查找各格的完整粒子范围；位置、旧位置和速度同步重排为连续邻域。两档均为 24 个排序 pass，无固定邻域桶截断。
- 两档均使用三次基于位置的压缩密度投影、碰撞和速度平滑都在片元着色器中完成。物理核半径 0.17、搜索格宽 0.225 和单次校正上限 0.017 都乘以精度尺度，为最多三次校正保留邻域余量。按最坏校正位移保守剔除不可能包含邻居的网格，先比较平方距离再开方。只在过密时产生排斥，没有负压吸引或弹性弹簧。
- 密度校正后预计算 DFSPH 系数，执行两次松弛 Jacobi 速度散度投影，共增加五个 GPU pass；复用现有邻域，不增加排序或 CPU 回读。稀疏喷溅不进行自身散度约束。当前为 PBF 密度校正 + DFSPH 速度投影的混合求解，并非完整 DFSPH。
- 固体墙面参与密度和压力梯度计算：解析积分二次径向核在墙外半空间的贡献，角落用近似并集避免重复计入。密度校正与速度投影使用同一边界项，墙不作为可移动粒子；碰撞保留切向滑动。修复粒子被夹成墙面水片后，压力缺少离墙方向而锁住的问题。
- **正常视图不绘制粒子小球。** GPU 实例化投射平滑粒子核，以 R16F 浮点相加重建 128 × 160 × 96 的三维密度场，存于 8 × 12 切片图集。每个粒子最多覆盖 20 个 Z 切片；只在调试模式下显示独立粒子。喷溅的稀疏粒子根据邻域密度将重建核半径平滑缩小到 0.10，主体水体基准半径 0.19，随精度缩放，喷溅半径下限 0.095；更细体素、光线步长与法线差分避免小水滴漏采样。此调整改变表面重建，不改变物理粒子质量。
- 根据邻域协方差构造各向异性核，平滑仅用于渲染的核中心；一次 GPU MRT 输出中心与三个矩阵列，物理位置不被渲染平滑修改。椭球边界缓存到矩阵纹理 W 分量，每粒子仅预计算一次。
- 三个 GPU pass 沿三维水面的切向滤波密度，法向滤波减弱以控制水位偏移。使用原始场在三个方向的最大密度统一判定连续水体；孤立水滴跳过滤波，空区域提前返回，图集边界按三维坐标寻址。
- 光线步进对图集执行三线性采样，找到连续等值面，由密度梯度计算法线。GPU 最大值归约提供水体高度边界，减少空区域步进，不读取 GPU 数据到 CPU。

参考 [Position Based Fluids](https://matthias-research.github.io/pages/publications/pbf_sig_preprint.pdf) 与 [粒子流体表面重建](https://matthias-research.github.io/pages/publications/sca03.pdf)。GPU 浮点缓冲使用 [EXT_color_buffer_float](https://registry.khronos.org/webgl/extensions/EXT_color_buffer_float/)；不支持时显示明确错误，不悄悄退回 JS 物理。

## 按水体厚度吸光

折射光线穿过密度场时，累积实际位于重建水体内部的路径长度，再按 `T = exp(-absorption * opticalPath)` 分别计算 RGB 透过率。红光衰减较快：薄层接近无色透明，较长水中路径呈青蓝色。不再使用会饱和的 8 位粒子亮度叠加估计厚度，也没有为所有水体叠加固定的青色底色。

水体形态、厚度、法线来自同一个三维密度场。仍保留 Fresnel 环境反射、折射、水底棋盘透视与较弱的动态焦散近似。

## 范围与验证

这是有限分辨率的实时流体近似，非工程级仿真。压力约束可压缩，喷溅中孤立粒子有用于可见性的小尺度核补偿；体素重建不是严格保体积算法。固定容器、程序化环境和焦散为近似，折射按单次入射方向积分，没有求解多次界面折射或多重散射。

粒子状态与水体重建直接留在显存，调试粒子也从位置纹理读取。物理在固定 1/60 秒子步推进；上一帧超过 1/45 秒时，本帧最多推进一步，其他帧最多两步。丢弃超出预算的积压时间，防止慢帧触发多次补算而持续加重负载。重负载时模拟时间会放慢，速度倍率可能达不到设定值，粒子数和每步求解精度保持。画布分辨率按实际帧率调整，物理粒子数不会自动降低。原来的 Worker 快照插值已移除；高刷新率屏幕上的物理更新仍为 60 Hz。实际页面帧率包含物理、重建和光线步进成本，取决于设备。

### 浮力小鸭子（实验 012）

小鸭子采用 Khronos 示例库收录的 Sony 原始 Duck 模型：2,399 个顶点、4,212 个三角面和原贴图。资源位于 `public/models/duck/`，保留原始 GLB、作者说明与 SCEA 许可证。`scripts/prepare-duck.py` 只做统一缩放、平移和 BVH 打包，不生成或简化网格。

位置、四元数、线速度和角速度均保存在 GPU 的 4×1 状态纹理中。封闭鸭身的椭球碰撞代理向 PBF 密度约束提供固体核支持，压力修正、非穿透接触和局部切向阻力产生的反向冲量及力矩通过 MRT 累积、GPU 归约并作用到刚体。移动边界速度参与散度约束。没有指定水面高度、正弦摇摆动画或 CPU 粒子读回。静态池壁接触使用椭球支撑点；排空水体后鸭子受重力落地。质量与惯量模拟底部配重的封闭橡皮鸭，并非活鸭。

渲染对原三角网格做 BVH 光线求交，因此鸭身参与水面遮挡、反射、折射及水下光程截止；不是贴在水面上的图片。重建水面与简化碰撞壳仍存在有限分辨率误差。当前为固定 1/60 秒步长、分离求解的实时刚体/SPH 近似，不是经过实验标定的工程级流固耦合求解器；速度限幅、离散边界及水体全局阻尼也限制了严格的全局动量守恒。

验证：`node --test tests/gpu-fluid.test.mjs`；macOS 原生 GPU 上运行 `python3 tests/gpu-duck.test.py 15000` 与 `30000` 检查静水沉浮、姿态、扰动响应和排水落地；`python3 tests/gpu-duck-model.test.py` 比较 GPU BVH 与原模型逐三角形求交。此验证不包含浏览器视觉检查或浏览器帧率测量。
