# WATER · 水体实验室

基于原生 WebGL / GLSL 的交互式三维水体网页。React 管理界面，GPU 计算水体相交、波浪法线与光学着色，无远程纹理或字体依赖。

## 运行

```sh
npm install
npm run dev
```

浏览器打开终端给出的本地地址。`npm run build` 生成部署产物，`npx tsc --noEmit` 检查类型。

## 交互

- 点击水面或“添加涟漪”施加扰动；拖动旋转，滚轮缩放。
- 水体标签调整波浪强度、流速、水深；提供静水、涟漪与风浪预设。
- 光照标签调整亮度，切换环境反射、水底焦散。
- 支持暂停、重置与触屏拖动。聚焦画布后，方向键旋转，+/- 缩放，回车或空格施加涟漪。

## 渲染方式和范围

有限体积水体通过光线与波浪高度场和侧面的相交表现体积。多方向正弦波与衰减径向波产生实时法线变化；折射使用折射率 1.333，吸光使用 Beer–Lambert 形式，反射混合使用 Schlick Fresnel 近似。天空反射环境与水底焦散均为程序化近似。

这是实时水体视觉模拟，不是完整的 Navier–Stokes 流体求解器，不包含自由溢出、破碎浪或真实多次散射。需要浏览器支持 WebGL 和硬件加速。可选 WebMCP 工具仅在支持 document.modelContext 的环境注册；当前运行环境未提供此 API 的专门验证上下文。
