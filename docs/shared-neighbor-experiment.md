# 网格共享邻居与线程组实验（2026-09-10）

基线：`b99e3742494da3b870ae3ae0f31b654931e98bea`。本轮所有实现都在实验脚本中，网页运行代码没有改动，未推送或发布。结论：当前设备、五万粒子场景下没有性能收益，保留现有实现。

## 共享读取方案

重新分桶后，在 GPU 上生成紧凑任务列表，每个任务处理同一单元内的一组粒子；密集单元拆分为多个任务，避免固定容量截断。通过间接调度只执行非空任务。每组线程将邻居位置分批载入工作组共享内存，然后各自计算原有相互作用。仍保存完整 u32 邻居编号及原有的 96 邻居缓存溢出回退。

只替换排序刚更新后的压力收集和速度准备内核。压力修正后、排序尚未更新的一轮继续用原来的搜索，避免用旧单元归属查询新位置。没有修改物理步长、迭代次数、质量、张力、核函数、粒子数量或渲染效果。

新增任务缓冲约 0.8 MB（五万容量），每次重建网格多一个任务构建 pass，工作组共享位置占 512～2048 字节。同步使用 WGSL 的 `workgroupUniformLoad` 和 `workgroupBarrier`，闲置线程仍参与同步。参见 [WGSL 规范](https://www.w3.org/TR/WGSL/#workgroupBarrier-builtin)。

## 完整 GPU 区间测量

M3 Pro / 原生 Metal，五万粒子，1250×800，平静场景，完整物理、密度重建、鸭子、反射与焦散。预热 120 次模拟，保存粒子、鸭子、上一轮反作用力和时间；每次测量恢复同一输入，每两帧交替版本。80 帧舍去前 20 帧，用 GPU 时间戳测量第一物理 pass 到最终渲染结束，包含任务构建成本，使用现有分段提交。

| 实验                    | 原始平均 | 实验平均 | 耗时变化 |
| ----------------------- | -------: | -------: | -------: |
| 同单元共享位置，32 线程 | 22.37 ms | 23.32 ms |    +4.3% |
| 原始搜索，仅改 32 线程  | 24.35 ms | 25.34 ms |    +4.0% |
| 原始搜索，仅改 64 线程  | 22.71 ms | 23.38 ms |    +2.9% |
| 原始搜索，仅改 256 线程 | 19.79 ms | 20.08 ms |    +1.5% |

共享 32 线程方案用保存后的复现脚本再测一次：原始 20.78 ms，共享 21.87 ms，慢约 5.2%，方向与首轮一致。

原始线程组为 128。仅比较同一行的交替结果，不比较跨轮绝对耗时；机器负载、热状态与初始化后的模拟状态会变化。这些时间不是浏览器 FPS。没有测七万粒子或浏览器呈现性能，也没有据此声称其他 GPU 上结果相同。

## 分项结果与限制

在同一份平静粒子状态上，分别测试 32、64、128 线程的共享读取，以及相同任务组织但直接读取全局内存的版本。每个内核连续执行 40 次，以减少时间戳量化影响；交替四轮，舍去第一轮。六种组合的压力收集与速度准备均慢于原始内核，即使不计构建任务的额外成本也无收益。

该状态只有 2843 个非空单元，且各单元均能装进 32 线程组，平均每单元约 17.6 个粒子。因此 32 线程单元任务的有效线程比例约 55%，增大工作组会进一步增加空闲线程。数据表明这种任务组织不适合当前状态；共享同步、闲置线程及原有硬件缓存可能共同影响结果，但没有硬件计数器或单独屏障测量，不能把差值全归因于其中一项。

## 正确性验证

- 共享版本通过独立 CPU 全粒子邻居、密度、压力和粘度对照。
- 覆盖 513 粒子的稀疏输入、空邻居、跨单元、512 张超过 96 邻居的密集列表、连续压力修正与缓存刷新。
- 三种共享线程宽度及直接读取变体，在五万粒子固定状态上的压力和速度准备因子与基线最大绝对误差为 0。
- 单独改为 32 线程的原始搜索也通过全粒子对照。64/256 线程完整帧测试无 GPU 验证错误，但没有分别跑完整长期物理验证；这些方案没有接入。
- 没有浏览器视觉 QA。正式运行代码完全不变，因此未重复构建或长期回归。

## 复现

从项目根目录运行，需要能访问 Metal GPU 的本地 Node 环境：

```sh
node --experimental-strip-types docs/experiments/shared-neighbor-correctness.mjs
node --experimental-strip-types docs/experiments/shared-neighbor-benchmark.mjs
MODE=shared WIDTH=32 node --experimental-strip-types docs/experiments/shared-neighbor-frame-benchmark.mjs
MODE=workgroups WIDTH=64 node --experimental-strip-types docs/experiments/shared-neighbor-frame-benchmark.mjs
```

分项脚本比较固定状态下的内核；完整帧脚本包含模拟和渲染。`MODE=workgroups` 使用原有搜索，仅调整六个邻居内核的线程组大小。实验脚本通过运行时挂接实现，页面不导入它们。[完整帧测量数据](./experiments/shared-neighbor-results.json)保留本次实测结果。
