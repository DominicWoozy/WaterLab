# 拟真优先的静水求解（本地验证）

当前 WebGPU 设置采用每个 1/60 秒调度周期内的 **3 个 1/180 秒物理子步**，每个子步做 **4 轮松弛位置压力修正**和 **2 轮速度散度投影**。粒子数量、质量、重力、张力参数及水面重建保持原有设置。未发布。

## 为什么改变求解方式

最初版本 `3f56b92f055e66a99199b198182e6ca91788f474` 每周期使用三轮全幅位置修正。邻居约束同时修正容易过冲，并通过 `(position - oldPosition) / dt` 将位移带回速度，静水也持续振荡。关闭张力仍能复现。

上一版本用五轮、0.25 松弛系数显著降低振荡，但 50,000 粒子的静水正压缩误差 RMS 约 5.4%。本轮保留松弛，改用更小的时间步和更充分的求解，使每次重力预测后的压缩量更小，而不是增大粘度或锁定小速度。

参考 [Small Steps in Physics Simulation](https://mmacklin.com/smallsteps.pdf) 对子步与迭代分配的分析，并保留现有 PBF/速度投影混合架构。[DFSPH 作者的算法示例](https://interactivecomputergraphics.github.io/physics-simulation/examples/dfsph.html)以压力残差控制求解精度；本版本仍使用固定预算，不能称为完整的自适应 DFSPH。

本地对照中，2 个子步 × 9 轮与 3 个子步 × 4 轮均达到静水目标；后者减少邻居遍历。4 个子步 × 2 轮的误差接近 1% 上限，最终选择余量更大的 3 × 4 配置。

## 保持力与时间的一致性

- 重力、拖拽、摇晃及张力按物理子步积分。点击溅水作为一次性冲量，只作用于首个子步；注水也只初始化一次。
- XSPH 粘度乘以子步长度与原步长之比；速度耗散和鸭子接触切向耗散按时间指数缩放，避免子步增加导致粘度、摩擦成倍增加。
- 每两轮压力修正重新分桶，并同步排列鸭子的压力反作用。流体及鸭子使用一致的实际子步长度计算冲量。
- 两个调度周期可批量提交。每个物理子步使用独立常规/反作用重置参数，重建和场景重置另有独立参数，避免队列提交前的写入覆盖。
- GPU 基准从第一个物理子步开始计时，覆盖整个调度周期的求解和渲染。

## 精度验证

原生 Metal，50,000 粒子，重力 9.8、粘度 0.025、无持续扰动。按粒子 ID 对齐逐帧状态，避免分桶重排形成虚假位移。压缩指标为 `RMS(max(rho / restDensity - 1, 0))`，不是每个粒子的最大误差，也不是整体水体体积变化百分比。位移与速度使用当前场景单位。

最终配置的代表性记录如下（静水先演化 15 秒，再采样 24 个调度周期）：

| 粒子数/条件 | 正压缩 RMS | 位移 RMS / 调度周期 | 速度 RMS |
| ----------- | ---------: | ------------------: | -------: |
| 50k，张力开 |     0.843% |           0.0000910 |  0.00571 |
| 50k，张力关 |     0.845% |           0.0001098 |  0.00655 |
| 30k，张力开 |     0.599% |           0.0000556 |  0.00391 |
| 15k，张力开 |     0.382% |           0.0000582 |  0.00420 |

连续搅动与强冲量的独立数值测试中，50k 的正压缩 RMS 约为 **1.26%**，因此不将静水的 1% 指标宣称为任意动态状态的上限。

50k 强扰动后的速度 RMS 从约 0.674 降到 15 秒后的 0.0285，再降至 30 秒后的 0.00505；恢复后的压缩 RMS 为 0.849%。鸭子平均支撑力为 0.254913，模型重量为 0.254800，差约 0.044%。这些是当前模型中的力单位，不视为真实鸭子的实验标定。

更严格的 `npm run test:webgpu:settling` 要求：

- 15k、30k、50k 的静水压缩 RMS 均小于 1%；50k 同时测试张力开启和关闭。
- 逐帧位移 RMS 小于 0.0004，速度变化 RMS 小于 0.006，速度随模拟时间衰减。
- 强扰动必须产生明显运动，并在 30 秒后重新通过静水标准，不立即抹掉真实波浪。
- 浮动鸭子保持在池底上方，平均流体支撑力与模型重量相差小于 10%。

数值回归另检查：强扰动的压缩误差、密度场独立参考值、分桶、清空/注水，以及单颗水滴的弹道和批量提交。弹道测试使用不同重力和一次性溅水，验证模拟时长、冲量次数与参数隔离。分桶参考计算使用与 WGSL 相同的 f32 运算精度，避免恰好位于格面时，JS 双精度参考值误判。

## 范围与限制

这是精度提高后的实时近似。1% 目标针对静水的正压缩 RMS；自由表面缺邻居、强碰撞与注水仍可能有更大的局部或瞬时误差，不能声称每个粒子、所有时刻均小于 1%。浮力平衡测试验证当前耦合的一致性，不等于完成真实水体参数的实验标定。

M3 Pro 原生 Metal、1250×800，张力、反射、焦散和水滴细节开启，相同状态交替对照的 GPU 命令区间：上一版五轮求解平均 **17.57 ms**（P95 19.40 ms），最终拟真版平均 **33.20 ms**（P95 36.70 ms），增加约 **15.63 ms / 89%**。这是用户选择拟真优先后的明确代价。

本轮没有浏览器视觉 QA，没有修改反射或添加时间滤波来掩盖物理误差。性能测量使用同一粒子/鸭子状态交替执行两个版本，包含物理、水体重建和渲染的 GPU 命令区间，不包含浏览器显示合成，也不能直接换算为保证的网页帧率。
