# 7 万 / 10 万粒子档位

新增 WebGPU 70,000 和 100,000 选项，默认仍为 50,000。WebGL2 保留 15,000 / 30,000，上层收到更高档位时回退到 30,000；界面在 WebGL2 下禁用高档位。

## 改动

- GPU 容量、注水上限和状态显示统一为 100,000。索引沿用完整 u32，粒子 ID 的 f32 表示在这个范围内也保持精确。
- 初始化分别使用 `100×70×10` 和 `125×80×10` 的排列，保持原始水块范围。原有档位的排列不变；粒子质量和物理支持半径继续随档位缩放。
- 固定 32×40×24 空间网格的单元尺寸不再小于 50k 对应尺寸，避免高精度下容器右侧和顶部超出网格的真实覆盖范围。压力、速度准备和体积重建使用相同尺寸。只扩大候选分区，不扩大物理核。
- 鸭子受力中间缓冲扩展至 `ceil(100000/256)` 组，最终归约循环读完全部组，修复超过 65,536 粒子时原来的 256 组容量限制。线性冲量和角冲量都完整汇总。
- 高档位每个子步使用 6 轮压力修正；原来的 15k / 30k / 50k 保持 4 轮。时间步、张力、投影轮数和渲染设置保持原有配置。初次沿用 4 轮时，70k 静水压缩 RMS 约 1.05%，未达到原有 1% 目标，因此增加高档位求解轮数。
- 未接入此前没有整帧收益的压缩邻居、共享读取或专用内核实验。

目前统一预留最大容量；粒子相关的模拟与重建缓冲比 50k 容量约增加 38.6 MB，纹理分辨率不变。这是已分配缓冲的变化，不是整个浏览器的显存统计。高档位需要更多计算时间，不保证 60 FPS。

## 验证

M3 Pro 原生 Metal，固定 1/180 秒物理子步，模拟 15 秒后取 24 帧窗口：

| 档位 | 静水压缩 RMS | 速度 RMS | 每帧位移 RMS | 平均鸭子支撑力 |
| ---- | -----------: | -------: | -----------: | -------------: |
| 70k  |       0.694% |  0.00895 |     0.000148 |        0.25510 |
| 100k |       0.884% |  0.01086 |     0.000181 |        0.25512 |

两档通过现有静水压缩、速度、位移与速度变化阈值。模型重量为 0.2548，支撑力与重量相差均小于 0.2%。这些数值使用本项目的模拟单位与密度定义，不代表实验标定后的真实水体误差。

新增 `npm run test:webgpu:high-quality` 验证高档位切换、完整唯一 ID、初始体积、全量归约，以及旧网格覆盖范围外的容器右上角邻居和独立密度求和。另通过：

- `HIGH_QUALITY=1 npm run test:webgpu:settling`：高档位静水与浮力平衡。
- `npm run test:webgpu:neighbors`：独立全粒子压力、密度、粘度和缓存溢出回退。
- `npm run test:webgpu:volume-reuse`：五个档位完整重建与缓存重建对照、孤立水滴、溢出、清空。
- 呈现调度测试：8 项通过，包含高档位切换回原档位与 WebGL2 回退。
- TypeScript、修改后的模拟与测试文件 lint、两种生产构建通过。`app/page.tsx` 的完整 lint 仍有三项原有问题（render 中写 ref、effect 中同步 setState、内部链接使用 a）；在基线源码也可复现，本轮未修改对应代码。

100k 完整物理与渲染测试通过，无 GPU 验证错误：1250×800、反射与焦散开启，原生 GPU 区间平均约 52.61 ms，完成帧平均约 53.26 ms。它验证完整路径可运行，不是浏览器帧率承诺，也不是高规格 GPU 的性能上限。未进行浏览器截图或视觉 QA。本地预览 HTTP 200。
