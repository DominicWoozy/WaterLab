# 可选水体自反射与水面自阴影

2026-09-11，两个开关默认关闭，保留为可选实验。试用反馈认为当前场景的视觉改善不明显，暂不作为默认画质。

## 行为与边界

光照面板增加「水体自反射」和「水面自阴影」，只在 WebGPU 后端可用。自反射依赖原有环境反射开关；自阴影可以单独开启。重置恢复默认关闭。WebMCP 的 configure_water 同步支持 selfReflection / selfShadow。

- 自反射在现有三维密度场内找另一处自由水面，受鸭子和地面最近交点限制。命中后计算那层水的透射、吸收和环境反射，最多增加一层反射；其透射继续采用既有的有界多界面算法。
- 自阴影向太阳方向跟踪其他水层，按水内光程做带颜色的吸收和近似 Fresnel 衰减；鸭子作为不透明遮挡。影响水面日光高光、环境太阳亮斑及原有近似散射项，保留环境照明。平坦水面不会遮挡自身。
- 容器裁切面的接触不当作自由反射面，也不会额外产生一次阴影 Fresnel 衰减。
- **这是有界实验近似，不是完整全局光照。** 阴影射线保持直线，没有求解折射后连接太阳的真实光路；水面聚焦焦散、无限多次水面反弹不包含在内。次级射线只查询密度场，无法单独命中小于体素的解析水滴；这些小水滴作为相机可见表面仍可接收新增光照。
- 物理、粒子数、密度重建均未改变。关闭时选择原始独立渲染管线，不增加逐像素光线追踪；启动时会多编译一个实验着色器。两项共用现有资源，没有新增三维纹理或逐帧缓存。

## GPU 性能

M3 Pro，原生 Metal WebGPU，1250 × 800，默认显式张力、反射/焦散/精细水滴开启。每组预热 120 个模拟 tick，再对相同恢复的粒子、鸭子、反作用和模拟时间交替启用/关闭效果。160 帧舍弃前 20 帧，各 70 帧；用 GPU 时间戳统计均值。生产管线自行按开关选择，基准不替换着色器。

## 验证

- GPU 解析场景：空场、平面防自相交、两个厚度水层的吸收/Fresnel、次级水面命中、最近接收面截断以及不透明遮挡。
- 完整生产图像：俯视/侧视/干场景，包含起伏水面、悬空水层、水滴和鸭子；两个开关独立及同时生效，所有像素有限。两种纹理采样路径均通过，干场景像素不变，关闭后精确恢复原图。
- 原有着色顺序图像回归、类型检查、展示与调度测试，以及 Sites / Pages 构建通过。
- 本地浏览器已确认两项默认关闭，可同时开启并恢复；画面正常且没有控制台错误。UI 帧率未作为上述性能基准。
