# 不改变求解预算的预计算优化（2026-09-10）

以已部署版本 `3b5d4f94028d7dc418ed3e779f09ee474938dc1d` 为基准，预计算粒子不变量以减少重复运算。保持 15k/30k/50k 粒子档位、三个 1/180 秒子步、四轮位置压力、两轮速度投影、张力与粘度公式、密度场分辨率、过滤、反射和焦散不变。

## 保留的变化

1. 几何重建时每个粒子只计算一次密度核半径和振幅。每个体素遍历候选粒子时读取结果，不再重复计算 `smoothstep`、插值及低密度振幅。半径不是缩小或放大，只是提前计算。64 字节的 Shape 记录重新安排原有标量槽：`center.w` 为半径、`m0.w` 为振幅、`m1.w` 保留原 rho；各向异性矩阵不变。
2. 速度准备阶段计算每个粒子的表面权重，放在原先未使用的 factor.w。粘度／显式张力遍历邻居时复用它，减少反复求法线长度和权重。每个物理子步重新计算，不跨位置或法线更新复用。可选隐式张力仍可使用原公式。

两项均复用已有缓冲区槽位，没有增加显存分配、GPU dispatch 或 CPU 回读。不改变邻居集合、作用半径、累计顺序或求解次数；编译器融合与中间 f32 存储可引入微小舍入差异，因此不承诺逐位一致或长期粒子轨迹完全相同。

## 测量

M3 Pro 原生 Metal，50,000 粒子、1250 × 800，开启现有水滴、张力、反射和折射焦散。保留发布版源码快照，与新版本在相同粒子／鸭子输入下每两帧交替运行，共 80 帧、去掉前 20 帧。沿用生产的分段 command buffer 提交，用 GPU 时间戳测完整物理到渲染区间。

| 场景 | 发布版平均 | 优化版平均 |           减少 | 发布版 P95 | 优化版 P95 |
| ---- | ---------: | ---------: | -------------: | ---------: | ---------: |
| 平静 |   22.64 ms |   21.58 ms | 1.06 ms / 4.7% |   25.76 ms |   23.13 ms |
| 大浪 |   21.98 ms |   21.13 ms | 0.85 ms / 3.9% |   23.72 ms |   22.02 ms |

不同场景分别测量，不能横向用其绝对时间判断场景复杂度。结果受设备负载和 GPU 时间戳量化影响，不包含浏览器合成或实际屏幕帧率。原有自适应分辨率机制未改动，交互中部分性能余量可能用于提高实际渲染分辨率。

单独开启半径／振幅预计算的对照节省约 0.80 ms；单独表面权重预计算的收益较小，约 0.15 ms。不能把不同轮实验的增量直接相加。

最初分阶段同步诊断约为物理 16.6 ms、密度重建 7.7 ms、渲染 3.3 ms，仅用于找瓶颈。同步诊断包含阶段等待开销，不能与上述交替 GPU 对照直接相减。

另外试过带完整位移余量的压力候选排除，以及增加 1.6 MB 的墙体／鸭子支持缓存，未观察到稳定收益，均未保留。更多缓存不必然更快，额外访存可以抵消减少的计算。

## 验证

新增 `npm run test:webgpu:invariants`，在相同状态下对照原来的逐邻居张力权重和逐体素密度参数公式：

- 覆盖 15k/30k/50k、超过 96 个缓存邻居的密集输入、孤立水滴和清空。
- 对照全部 1,966,080 个原始密度与最终过滤值，而不是只观察画面。
- 常规场景速度最大差异不超过约 4.8e-7，原始密度约 3.8e-6，过滤密度约 1.1e-5；极密集输入最大密度差约 3.1e-5。均在测试浮点容差内。
- 检查粒子状态和解析水滴数量不被重建修改。

另运行独立 CPU 密度对照、精确邻居／溢出回退、张力守恒、水滴重建、静水与浮力、呈现调度回归、TypeScript、修改文件 lint 和生产构建。没有浏览器视觉 QA。
