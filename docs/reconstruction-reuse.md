# 复用最终物理网格和邻居列表

粒子数量、时间步长、压力迭代、张力、重建核、密度场分辨率、折射、反射及焦散参数均未改变。

## 省掉的工作

最后一个物理子步在最终位置修正后已经重建网格，并通过 `prepareVelocity` 生成精确邻居列表。后续粘性、张力、速度投影只更新速度，鸭子积分也不修改粒子位置或索引。因此，同一帧的水体重建可以复用该网格，并使用相同支持半径的邻居列表计算各向异性形状。

活动帧省掉一次 count/scan/scanTotals/add/scatter，以及形状计算中的重复网格搜索。没有新增 GPU 缓冲区或缓存容量。邻居数超过 96 时仍退回完整网格遍历，不截断物理或几何贡献。

`WebGPUVolume.encode` 的第四参数默认关闭复用，只有刚完成 `sim.step` 的调用者可启用。动画循环逐帧记录是否实际完成了物理步；暂停中的重置、排水、细节开关和从粒子视图返回等情况走原有重建路径。每帧运行两个物理 tick 时使用最后一个的缓存。

## 验证

- `npm run test:webgpu:volume-reuse` 比较相同状态下两条路径的完整原始/滤波密度场、按粒子 ID 对齐的所有形状、物理状态和解析水滴。覆盖 15k、30k、50k、缓存溢出、孤立小滴及清空。
- 15k/30k/50k 的原始密度最大差约 4.77e-6，滤波场本次最大差约 6.68e-5，RMS 约 2e-7。浮点差异来自移除原子散射重排后的求和顺序；并非宣称逐位一致或长期粒子轨迹逐位一致。形状核和物理方程未改变。
- 极密集溢出场景原始密度最大差约 7.63e-5；保留完整遍历和原有滤波。
- 呈现回归 6 项通过，包括暂停、排水、重置、双 tick、调试切换和防闪烁调度；类型检查、修改文件 lint 和生产构建通过。未做浏览器视觉 QA。

## 性能

M3 Pro 原生 Metal，50k 粒子，1250 × 800，保留反射、焦散及小滴细节；固定输入交替比较两条路径。这里测的是 GPU 命令区间，不含浏览器合成。

首次平静对照平均 26.87 → 26.25 ms，大浪对照 37.89 → 37.27 ms。最终可复现基准的平静对照为 21.61 → 21.26 ms，P50 为 21.43 → 20.97 ms。系统负载会改变绝对时间，几次对照节省约 **0.3–0.6 ms / 1.5–2.3%**；属于小幅优化，不保证浏览器帧率提升相同比例。

复现命令：

```sh
REUSE_GRID=alternate PAIRED=1 SPLIT=0 npm run benchmark:webgpu -- 50000
SCENE=rough REUSE_GRID=alternate PAIRED=1 SPLIT=0 npm run benchmark:webgpu -- 50000
```

曾试过缓存边界支持/鸭子法线，以及扩大位移安全范围的网格剔除；对照未显示收益，已撤回。主要开销仍在物理求解；更多缓存或更复杂的剔除不一定更快，需要分别测量。
