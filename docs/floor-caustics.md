# 多界面折射焦散与接收面光照

WebGPU 光照已从连续水池的池底焦散扩展到悬空水体、空气间隙、池外地面和鸭子表面。WebGL2 仍使用原有池底近似；粒子物理和水体重建参数不变。

## 光的传播与接收

空气不会使焦散消失。光线进入水体、穿出水体时分别折射，随后沿空气中的新方向继续寻找接收物；水曲面的聚光与散光决定落点和强度。旧实现拒绝干燥接收面及较长空气间隙，是实现限制。

新流程：

1. 从既有太阳方向 `normalize(-0.6, 1, 0.35)` 发出 384 × 320 条光线，源网格覆盖 12 × 10 场景单位。起点高于水体和鸭子。
2. 在当前三维密度场中求水体交点，同时用鸭子 BVH 和水平接收面求最近的不透明表面。
3. 遇到空气／水界面，按 Snell 定律计算方向（折射率 1.333），使用非偏振介质 Fresnel 透射系数；水中按 RGB Beer 吸收衰减，空气段不加水体吸收。发生全内反射时继续反射路径。
4. 最多经过 8 次界面事件、768 次密度步进采样；每个交点另做 6 次二分细化。连续经过多层水片或空气间隙后仍能抵达接收面。
5. 瓷砖平台 `y=-0.97` 与周围地面 `y=-1.075` 接收光。相邻光线落点组成三角形，按源网格与投影面积之比计算照度，加法投影到 1280 × 1024 的 `rgba16float` 纹理，覆盖 10 × 8 场景单位。
6. 鸭子接收自身真实三维表面上的光子命中，后续计算着色器把照度聚集到三角形顶点，最终材质按重心坐标插值。光子在 64 线程工作组内分批共享，不需 CPU 回读。模型的材质 UV 重叠，因此不把照度写入其原始 UV 纹理。

照度调制实际物体的直接光照，保留环境光。水面通过现有视线折射显示后方受光物体，不直接叠加发光花纹。关闭“折射焦散”时保留普通鸭子遮挡和直接照明；关闭光照、切换粒子调试时跳过新光照流程。空池保留正常直接照明，不会残留上一帧水体焦散。

## 成本

当前光照相关数据约 19.0 MB，比此前池底版本增加约 16.1 MB：

- 世界照度纹理：10,485,760 字节。
- 光线记录：7,864,320 字节。
- 鸭子光子索引：491,520 字节。
- 当前鸭子 12,672 个三角形顶点的照度：202,752 字节。
- 少量 uniform 和计数器。

M3 Pro，原生 Metal，50,000 粒子、1250 × 800，固定每次对照的粒子和鸭子状态，交替执行旧池底版本与新版本。80 帧去除前 20 帧，完整 GPU 命令区间均值：

| 场景     |     旧版 |     新版 |           增量 | 新光线追踪与地面投影 | 鸭子照度聚集 |
| -------- | -------: | -------: | -------------: | -------------------: | -----------: |
| 平静模式 | 23.48 ms | 23.80 ms | 0.32 ms / 1.4% |              0.77 ms |      0.10 ms |
| 大浪模式 | 21.42 ms | 22.08 ms | 0.66 ms / 3.1% |              0.97 ms |      0.10 ms |

两个场景是分别测量，不能用其绝对时间比较场景复杂度。新增阶段总时间与相对旧版增量不是同一指标；旧版也有焦散计算。时间戳存在量化和运行波动，鸭子约 0.10 ms 仅代表量级，且不包括共享光线追踪中与鸭子求交的成本。这些数字不包含浏览器合成，不是跨设备帧率保证。

## 验证

`npm run test:webgpu:caustic-map` 使用生产管线和可控密度场，检查：

- 平水面近乎均匀照明、独立 Snell 落点计算、真实波形变化与仅时钟变化的区别。
- 悬空平行水片的两次折射、空气段不吸收、独立 Fresnel 与水中路径吸收。
- 两层水片的四次界面穿越，以及倾斜出水面的全内反射。
- 悬空水球在池外地面形成聚光与变暗。
- 鸭子遮挡、真实三维表面受光；共享材质 UV 的不同空间位置有不同照度。
- 头顶悬空波面改变鸭子照度；空池、清空粒子和开关不留下旧光纹。

`npm run test:webgpu:caustics` 检查实际接收坐标、干地面受光、鸭子受光与地面投影分离、遮挡、透射吸收与 Fresnel 合成，以及灯光／调试／暂停状态。

两组测试均覆盖硬件线性与手动三线性采样。另验证水体细节渲染、呈现稳定性、TypeScript、光照与测试代码 lint 及两种生产目标构建。页面原有的 3 条 lint 报错仍在，与本次两处标签文案修改无关。使用原生 GPU 输出图检查整体渲染；未做浏览器视觉 QA。

## 近似范围

- 这是直接光照的有限光线采样，未实现完整路径追踪、体积散射或多次漫反射。除全内反射外不继续追踪 Fresnel 反射分支。
- 接收对象为当前瓷砖、附近地面和鸭子；透明池壁仍是装饰显示，不作为额外光学介质。世界照度纹理范围以外保持普通直接照明。
- 主水体由现有密度场求交；小于密度场分辨率、仅用解析粒子轮廓显示的细小水滴尚未单独加入光线求交。
- 接口、步数和投影面积比有上限；跨接收面、跨界面数量或明显水团断裂的波前三角形丢弃。这些约束会损失部分能量，边界和细小水团附近可能有采样缺口，不能称为严格全局能量守恒。
- 鸭子用有限半径光子核和顶点插值，细光纹会变软；用法线相容性检查降低隔着薄模型串光的风险，仍属于有限分辨率近似。
- 本次改的是光源到物体的传播。相机主水面的视线折射仍沿用此前近似，未同步改成完整多次出入水追踪；这部分仍会影响悬空水片的视觉真实性。
